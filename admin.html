Správa Atlasu škodovek

GitHub · živá správa celého Atlasu

Propoj administraci s repozitářem Berniocal/skoda (větev main). Potom můžeš modely, popisky a fotografie uložit jedním kliknutím pro všechny návštěvníky. Dole najdeš i editor HTML, CSS, JavaScriptu a JSON souborů.

Bezpečnost: token vytvoř jen pro repozitář skoda a povol pouze Repository permissions → Contents → Read and write. Vyplňuj ho výhradně tady v administraci, nikdy do chatu ani do zdrojového kódu. Token zůstává jen v paměti otevřené stránky a po obnovení zmizí. Vytvořit token na GitHubu ↗
Nepřipojeno. Lokální editor můžeš používat i bez tokenu.
Katalog: po připojení klikni na Načíst z GitHubu, uprav libovolné modely a klikni na Zveřejnit katalog na GitHubu. Změny vytvoří commit přímo na větvi main. Lokální uložení a export JSON zůstávají jako záloha.
